# Demo de sitio jurídico

Prototipo visual de una landing page para un estudio ficticio de derecho de familia. **No representa a un profesional ni a un estudio real.** Los nombres, trayectoria, matrículas, testimonios y datos de contacto que aparecen en la interfaz son contenido de ejemplo y no deben usarse como información verdadera.

El formulario es parte del diseño de muestra; el repositorio no incluye un servicio backend para recibir consultas.

## Tecnologías y estructura

- HTML
- CSS
- JavaScript
- Vite
- Google Fonts y Font Awesome cargados desde CDN

`src/main.js` usa `IntersectionObserver` para activar animaciones al desplazarse.

## Ejecución local

Requiere Node.js y npm.

```bash
npm install
npm run dev
```

Para compilar y previsualizar la versión de producción:

```bash
npm run build
npm run preview
```

## Alcance

Es una demo de presentación visual. No es asesoramiento jurídico, no verifica credenciales profesionales y no procesa formularios.
